API

Web3Service

Costruttore e metodi di istanza.

Firma
new Web3Service(input: IEvmProvider | string, options?: Web3ServiceOptions)
Esempio
const web3 = new Web3Service('https://rpc-amoy.polygon.technology', { signer: { privateKey: process.env.PRIVATE_KEY! } });

web3.provider.nativeCurrency.symbol; // 'ETH': i default di Ethereum, salvo configurazione
web3.chainId;                        // '0x1', esadecimale minuscolo
Firma
public Web3Service(string rpcURI, Web3ServiceOptions? options = null)
public Web3Service(EvmProvider provider, Web3ServiceOptions? options = null)

public EthereumProvider Provider { get; } // configurazione con i default applicati
public string ChainId { get; }            // es. "0x13882"
Esempio
var web3 = new Web3Service("https://rpc-amoy.polygon.technology", new Web3ServiceOptions { PrivateKey = privateKey });

Console.WriteLine(web3.Provider.Symbol); // "ETH": i default di Ethereum, salvo configurazione
Console.WriteLine(web3.ChainId);         // "0x1", esadecimale minuscolo
ProprietàTipoDescrizione
providerReadonly<IEthereumProvider>Configurazione con i default applicati e il chain ID normalizzato (Provider in .NET)
chainIdstringChain ID normalizzato, es. 0x13882 (ChainId in .NET)

mint

Notarizza un documento chiamando mint(contractAddress, hash, algorithm, metadata). Come nella classe originale, il primo argomento è l’indirizzo del contratto stesso. Attende l’inclusione in un blocco.

Firma
mint(
  abi: Abi,
  contractAddress: string,
  document: NotarizationDocument,
  onChainEvent?: ITransaction,     // name e requestedAt da conservare
  options?: TransactionOptions,    // gas, gasPrice, nonce, value
): Promise<ITransaction>
Esempio
const result = await web3.mint(notarizerAbi, contractAddress,
  { hash: { data: hash, algorithm: 'sha2' }, metadata: 'ipfs://bafy...' },
  { name: 'contratto-42' },     // conservato nel risultato
  { gasPrice: '30000000000' },  // 30 gwei, opzionale
);
Firma
Task<TransactionResult> MintAsync(
    string abi,                              // ABI in JSON
    string contractAddress,
    NotarizationDocument document,
    TransactionResult? onChainEvent = null,  // Name e RequestedAt da conservare
    TransactionOptions? options = null,      // Gas, GasPrice, Nonce, Value
    CancellationToken cancellationToken = default)
Esempio
var result = await web3.MintAsync(abi, contractAddress,
    new NotarizationDocument { Hash = new NotarizationHash { Data = hash, Algorithm = "sha2" }, Metadata = "ipfs://bafy..." },
    new TransactionResult { Name = "contratto-42" },     // conservato nel risultato
    new TransactionOptions { GasPrice = 30_000_000_000 }, // 30 gwei, opzionale
    cancellationToken);

deploy

Firma
deploy(
  abi: Abi,
  bytecode: string,                         // 0x...
  constructorArguments?: readonly unknown[],
  onChainEvent?: ITransaction,
  options?: TransactionOptions,

Esempio

Firma
Task<TransactionResult> DeployAsync(
    string abi,
    string bytecode,                         // 0x...
    object[]? constructorArguments = null,
    TransactionResult? onChainEvent = null,
    TransactionOptions? options = null,
    CancellationToken cancellationToken = default) // indirizzo in Tx.ContractAddress
Esempio
var deployed = await web3.DeployAsync(abi, bytecode, new object[] { "CERTIFIE" },
    options: new TransactionOptions { Gas = 3_000_000 });
Console.WriteLine(deployed.Tx!.ContractAddress);

callContractMethod

Chiama un metodo in sola lettura. I numeri nel risultato diventano stringhe di interi, anche dentro array e oggetti.

Firma
callContractMethod<T = ContractResult>(
  method: string, abi: Abi, address: string, parameters?: readonly unknown[],
): Promise<T>
Esempio
// Un solo output restituisce il valore, più output un array; i numeri diventano stringhe.
const [storedHash, algorithm, metadataURI] = await web3.callContractMethod<string[]>(
  'metadata', notarizerAbi, contractAddress, [hash],
);
Firma
Task<JsonNode?> CallContractMethodAsync(
    string method, string abi, string address, object[]? parameters = null,
    CancellationToken cancellationToken = default) // più output in un JsonArray
Esempio
// Un solo output restituisce il valore, più output un JsonArray; i numeri diventano stringhe.
var outputs = (await web3.CallContractMethodAsync("metadata", abi, contractAddress, new object[] { hash }))!.AsArray();
var algorithm = outputs[1]!.GetValue<string>();

getTransactionReceipt

Recupera una transazione già inclusa, anche se revertita (in quel caso con error e rejectedAt). Utile dopo un errore TRANSACTION_SUBMISSION_FAILED, che riporta sempre transactionHash.

Firma
getTransactionReceipt(transactionHash: string, onChainEvent?: ITransaction): Promise<ITransaction>
Esempio
// Dopo TRANSACTION_SUBMISSION_FAILED la transazione potrebbe essere stata inclusa comunque.
const recovered = await web3.getTransactionReceipt(error.transactionHash!); // anche se revertita
Firma
Task<TransactionResult> GetTransactionReceiptAsync(
    string transactionHash, TransactionResult? onChainEvent = null, CancellationToken cancellationToken = default)
Esempio
// Dopo TRANSACTION_SUBMISSION_FAILED la transazione potrebbe essere stata inclusa comunque.
var recovered = await web3.GetTransactionReceiptAsync(exception.TransactionHash!); // anche se revertita

getContract

Restituisce un Web3Contract per l’ABI e l’indirizzo dati. Non contatta il nodo.

Firma
getContract(abi: Abi, address: string): Web3Contract
Esempio
const token = web3.getContract(tokenAbi, '0x...');
token.methods.find(method => method.name === 'transfer');
// { name: 'transfer', signature: 'transfer(address,uint256)', kind: 'write', stateMutability: 'nonpayable',
//   parameters: { to: 'string', amount: 'number' }, inputs: { to: 'address', amount: 'uint256' }, outputs: { result0: 'bool' } }
Firma
Web3Contract GetContract(string abi, string address)
Esempio
var token = web3.GetContract(tokenAbi, "0x...");
var transfer = token.Methods.First(method => method.Name == "transfer");
// Kind = "write", Parameters = { ["to"] = "string", ["amount"] = "number" }, Inputs = { ["to"] = "address", ["amount"] = "uint256" }

getTransaction

Legge una transazione per hash, anche in attesa. Con l’ABI decodifica la funzione chiamata. Se la transazione non esiste restituisce TRANSACTION_NOT_FOUND.

Firma
getTransaction(transactionHash: string, abi?: Abi): Promise<ITransactionDetails>
Esempio
const details = await web3.getTransaction(hash, tokenAbi);
details.pending;          // false una volta inclusa
details.value;            // '0': moneta nativa inviata, nell'unità minima
details.method;           // { name: 'transfer', signature: 'transfer(address,uint256)', parameters: { to: '0x...', amount: '250' } }
details.receipt?.status;  // '1'
details.nativeFee;        // { amount, symbol, decimals }
Firma
Task<TransactionDetails> GetTransactionAsync(
    string transactionHash, string? abi = null, CancellationToken cancellationToken = default)
Esempio
var details = await web3.GetTransactionAsync(hash, tokenAbi);
Console.WriteLine(details.Pending);                      // False una volta inclusa
Console.WriteLine(details.Method?.Name);                 // "transfer"
Console.WriteLine(details.Method?.Parameters["amount"]); // "250"
Console.WriteLine(details.Receipt?.Status);              // "1"
