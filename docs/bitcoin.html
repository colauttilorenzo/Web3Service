Blockchain

Bitcoin

Blocchi, commissioni e transazioni tramite un’API Esplora.

Con un IBitcoinProvider il servizio legge Bitcoin tramite un’API REST Esplora: quella pubblica di mempool.space o Blockstream, oppure un’istanza propria (electrs). Bitcoin non ha smart contract né token nativi, quindi i metodi su contratti e token restituiscono NotImplementedError. Le letture hanno lo stesso JSON delle altre blockchain.

Configurazione

Esempio
import { Web3Service, type IBitcoinProvider } from '@certifie/web3-service';

const provider: IBitcoinProvider = {
  kind: 'bitcoin',                           // sceglie Bitcoin
  rpcURI: 'https://mempool.space/api',       // API Esplora
  rpcPublicURI: 'https://blockstream.info/api', // fallback, opzionale
  chainId: 'mainnet',                        // mainnet, testnet, testnet4, signet o regtest
  blockExplorerURI: 'https://mempool.space',
};

const bitcoin = new Web3Service(provider);
Esempio
var bitcoin = new Web3Service(new BitcoinProvider
{
    RpcURI = "https://mempool.space/api",         // API Esplora
    RpcPublicURI = "https://blockstream.info/api", // fallback, opzionale
    ChainId = "mainnet",                           // mainnet, testnet, testnet4, signet o regtest
});
CampoDefaultNote
kind—Solo TypeScript: 'bitcoin'. In .NET lo indica la classe BitcoinProvider
rpcURI—URL base dell’API Esplora, obbligatorio
rpcPublicURI—API di fallback
chainIdmainnetVerificato con l’hash del blocco genesi; un nome diverso dalle reti pubbliche salta la verifica
chainNameBitcoin
nativeCurrencyBitcoin, BTC, 8Importi e commissioni in satoshi

Letture

Esempio
await bitcoin.check();
// { blockNumber: '868000', gasPrice: '4' }: altezza del blocco e commissione per il prossimo blocco in sat/vB

const details = await bitcoin.getTransaction(txid);
details.from;      // indirizzo del primo input
details.to;        // indirizzo del primo output
details.value;     // satoshi inviati ad altri indirizzi, senza il resto
details.pending;   // true finché non è in un blocco
details.nativeFee; // { amount: '1410', symbol: 'BTC', decimals: '8' }: commissione in satoshi

const receipt = await bitcoin.getTransactionReceipt(txid); // solo transazioni confermate
Esempio
var health = await bitcoin.CheckAsync(); // BlockNumber: altezza; GasPrice: sat/vB per il prossimo blocco

var details = await bitcoin.GetTransactionAsync(txid);
Console.WriteLine(details.Value);            // satoshi inviati ad altri indirizzi, senza il resto
Console.WriteLine(details.NativeFee?.Amount); // commissione in satoshi

var receipt = await bitcoin.GetTransactionReceiptAsync(txid); // solo transazioni confermate
CampoSu Bitcoin
hash, tx.transactionHashID della transazione (txid)
blockNumber, blockHash, transactionIndexAltezza, hash del blocco e posizione nel blocco
timestamp, completedAtOra del blocco in millisecondi
typeVersione della transazione
input, nonce, gas, gasUsed, logs'0x', '0' o vuoti

Operazioni non disponibili

getContract, callContractMethod, mint, deploy, createToken e getTokenInfo restituiscono subito NotImplementedError (NotImplementedException in .NET), senza contattare l’API. Vedi Operazioni non disponibili.

Nota

La firma e l’invio di transazioni Bitcoin non sono ancora supportati: il provider Bitcoin è in sola lettura e non usa le opzioni signer.
