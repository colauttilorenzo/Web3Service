Inizia

Introduzione

Blockchain EVM per backend, frontend e .NET, senza doverla conoscere a fondo.

@certifie/web3-service è la libreria che CERTIFIE usa per scrivere su blockchain l'impronta (hash) di un documento e dimostrare in seguito che esisteva in quella forma a una certa data. Distribuisce il contratto di notarizzazione, registra gli hash con mint, rilegge i dati dal contratto e restituisce ricevute con il gas speso, tutto su qualsiasi rete EVM: Ethereum, Polygon, reti private o un nodo locale.

Funziona anche con qualsiasi altro contratto: dato il suo ABI elenca i metodi con parametri in JSON semplice (string, number, boolean), li chiama per nome, riconosce gli standard ERC, crea NFT e legge token e transazioni. Chi sa usare un’API REST sa già usarla.

Funziona nel backend Node.js, nel browser (con il wallet dell'utente, per esempio MetaMask) e in .NET tramite un pacchetto NuGet nativo. Le tre versioni restituiscono lo stesso JSON.

Come funziona

Ogni operazione apre una connessione al nodo, verifica che il chainId sia quello configurato e la chiude al termine. Le scritture vengono firmate localmente (chiave privata o mnemonic) oppure dal wallet del browser, poi la libreria attende l'inclusione in un blocco e legge la ricevuta dal nodo.

import { Web3Service } from '@certifie/web3-service';

const service = new Web3Service('https://rpc.example', { signer: { privateKey: process.env.PRIVATE_KEY! } });

const result = await service.mint(abi, contractAddress, {
  hash: { data: 'e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855', algorithm: 'sha2' },
  metadata: 'ipfs://bafy...',
});

result.tx?.transactionHash; // '0x5c50...'
result.nativeFee;           // { amount: '48295000000000', symbol: 'ETH', decimals: '18' }

Cosa non fa

  • Non calcola l'hash del file: lo calcola la tua applicazione (vedi gli esempi con Web Crypto e Node).
  • Non carica file su IPFS o altri storage: metadata è una stringa che passi tu.
  • Non converte prezzi in valuta: restituisce solo il gas speso nel token nativo.
  • La notarizzazione con mint richiede un contratto che esponga mint(address,string,string,string); per gli altri contratti usa getContract.
