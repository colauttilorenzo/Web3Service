Blockchain

Più blockchain

Una sola API: il provider sceglie la blockchain.

Web3Service offre gli stessi metodi su ogni blockchain, descritti dall’interfaccia IWeb3Service. Il provider passato al costruttore sceglie l’implementazione: IEvmProvider (o un URI) per Ethereum e le reti EVM, IAvmProvider per Algorand, IBitcoinProvider per Bitcoin. Il codice che usa il servizio non cambia e il JSON restituito ha la stessa forma.

Esempio
import { Web3Service } from '@certifie/web3-service';

// Il campo kind distingue i provider; senza kind il provider è EVM.
const polygon = new Web3Service({ rpcURI: 'https://rpc-amoy.polygon.technology', chainId: 80002 });
const algorand = new Web3Service({ kind: 'avm', rpcURI: 'https://testnet-api.algonode.cloud', chainId: 'testnet-v1.0' });
const bitcoin = new Web3Service({ kind: 'bitcoin', rpcURI: 'https://mempool.space/api' });

polygon.kind;   // 'evm'
algorand.kind;  // 'avm'
bitcoin.kind;   // 'bitcoin'
await bitcoin.check(); // { blockNumber: '…', gasPrice: '…' }: stesso metodo, stessa forma
Esempio
using Certifie.Web3;

// La classe del provider sceglie la blockchain; va bene anche una tua classe che implementa l'interfaccia.
var polygon = new Web3Service(new EvmProvider { RpcURI = "https://rpc-amoy.polygon.technology", ChainId = "80002" });
var algorand = new Web3Service(new AvmProvider { RpcURI = "https://testnet-api.algonode.cloud", ChainId = "testnet-v1.0" });
var bitcoin = new Web3Service(new BitcoinProvider { RpcURI = "https://mempool.space/api" });

Console.WriteLine(algorand.Kind);     // "avm"
var health = await bitcoin.CheckAsync(); // BlockNumber, GasPrice: stesso metodo, stessa forma

Operazioni per blockchain

Un’operazione che la blockchain non ha fallisce subito, senza contattare il nodo, con NotImplementedError in TypeScript (codice NOT_IMPLEMENTED) e NotImplementedException in .NET.

MetodoEVMAlgorandBitcoin
checkSìSìSì
getContract, callContractMethodSìSì, applicazioni ARC-4NotImplementedError
deploySì, da bytecodeSì, da descrizione ARC-56 o programmiNotImplementedError
createToken, getTokenInfoNotImplementedError: i token EVM sono contrattiSì, Algorand Standard AssetNotImplementedError
getTransaction, getTransactionReceiptSìSìSì

Operazioni non disponibili

Il messaggio dice quale operazione manca e su quale blockchain, con un suggerimento quando esiste un’alternativa. Con un provider scelto a runtime puoi controllare prima kind, oppure intercettare l’errore.

Esempio
import { NotImplementedError, Web3Error } from '@certifie/web3-service';

try {
  await bitcoin.deploy(abi, bytecode);
} catch (error) {
  if (error instanceof NotImplementedError) {
    error.code;    // 'NOT_IMPLEMENTED'
    error.message; // 'deploy is not available on Bitcoin. Bitcoin has no smart contracts.'
  } else if (error instanceof Web3Error) {
    // gli altri errori della libreria
  }
}
Esempio
try
{
    await bitcoin.DeployAsync(abi, bytecode);
}
catch (NotImplementedException error)
{
    // "DeployAsync is not available on Bitcoin. Bitcoin has no smart contracts."
    Console.WriteLine(error.Message);
}
Nota

NotImplementedError estende Web3Error, quindi anche toJSON() e i gestori di errori esistenti funzionano. In .NET è la System.NotImplementedException standard, non una Web3Exception.

IWeb3Service

Per scrivere codice indipendente dalla blockchain, o per sostituire il servizio nei test, dipendi dall’interfaccia invece che dalla classe.

Esempio
import type { Abi, ContractParameters, IWeb3Service } from '@certifie/web3-service';

// Funziona con qualsiasi provider che abbia contratti: EVM o Algorand.
export function notarize(web3: IWeb3Service, abi: Abi, contract: string, parameters: ContractParameters) {
  return web3.getContract(abi, contract).send('mint', parameters);
}
Esempio
// Registrazione: la blockchain si sceglie nella configurazione, il resto dell'applicazione vede solo IWeb3Service.
builder.Services.AddSingleton<IWeb3Service>(new Web3Service(
    new AvmProvider { RpcURI = builder.Configuration["Algorand:Algod"]!, ChainId = "testnet-v1.0" },
    new Web3ServiceOptions { Mnemonic = builder.Configuration["Algorand:Mnemonic"] }));

app.MapPost("/notarize", (IWeb3Service web3, JsonObject parameters) => web3.GetContract(abi, contract).SendAsync("mint", parameters));
