Inizia

Installazione

npm, pnpm, yarn, bun, tag script o NuGet.

  1. Installa il pacchetto

    Con npm, pnpm, yarn o bun per Node.js e per i frontend con bundler (Vite, Next.js, Angular, webpack). Vanilla per le pagine senza bundler, NuGet per .NET.

    npm install @certifie/web3-service
    pnpm add @certifie/web3-service
    yarn add @certifie/web3-service
    bun add @certifie/web3-service
    <!-- Script classico: definisce il globale CertifieWeb3 (circa 300 KB gzip, dipendenze incluse) -->
<script src="https://cdn.jsdelivr.net/npm/@certifie/web3-service@0.2.0/dist/browser/web3-service.min.js"></script>

<!-- Oppure come modulo ESM -->
<script type="module">
  import { Web3Service } from 'https://cdn.jsdelivr.net/npm/@certifie/web3-service@0.2.0/dist/browser/web3-service.esm.min.js';
</script>

<!-- Oppure in locale: copia dist/browser/web3-service.min.js nella cartella pubblica del sito -->
<script src="/vendor/web3-service.min.js"></script>
    # Client C# nativo per .NET 6+ e .NET Standard 2.0, non avvia Node.js
dotnet add package Certifie.Web3Service

# Pacchetto locale, finché non è pubblicato su nuget.org
dotnet add package Certifie.Web3Service --source ~/Desktop/workspace/web3-service/artifacts/nuget
    Nota

    Finché il pacchetto non è pubblicato sul registry, installa il tarball generato con npm pack: npm install ~/Desktop/workspace/web3-service/typescript/certifie-web3-service-0.2.0.tgz (anche con pnpm, yarn e bun). In un progetto .NET puoi anche scrivere <PackageReference Include="Certifie.Web3Service" Version="0.2.0" /> nel .csproj.

  2. Configura le variabili d’ambiente

    Nel backend tieni chiave e nodo fuori dal codice.

    .env
    RPC_URL=https://rpc-amoy.polygon.technology
RPC_FALLBACK_URL=wss://polygon-amoy.example
CHAIN_ID=80002
CONTRACT_ADDRESS=0x...
PRIVATE_KEY=0x...        # oppure MNEMONIC="..." e WALLET_INDEX=1

Requisiti

  • Node.js 20 o superiore, oppure un browser con supporto ES2022.
  • TypeScript 5 per i tipi (opzionale).
  • .NET 6 o superiore per il pacchetto NuGet.
