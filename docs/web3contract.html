API

Web3Contract

Un contratto qualsiasi: metodi, chiamate per nome, token e NFT.

Si ottiene da web3.getContract(abi, address) e usa la connessione, il signer e la coda delle scritture del servizio che l’ha creato. Su Algorand l’indirizzo è l’ID dell’applicazione e l’ABI è la sua descrizione ARC-4, ARC-32 o ARC-56: vedi Algorand.

Firma
abstract class Web3Contract { // un'implementazione per blockchain, da getContract
  readonly abi: Abi;
  readonly address: string;                     // ID dell'applicazione su Algorand
  readonly methods: readonly IContractMethod[]; // nome, tipo (read, write, payable), parametri
  readonly standards: readonly string[];        // es. ['ERC-721', 'ERC-721 Metadata', 'ERC-165'] o ['ARC-200']
}
Esempio
const nft = web3.getContract(nftAbi, '0x...');
nft.address;    // '0x...'
nft.standards;  // ['ERC-721', 'ERC-721 Metadata', 'ERC-165']
nft.methods.filter(method => method.kind === 'read').map(method => method.name);
Firma
public abstract class Web3Contract // un'implementazione per blockchain, da GetContract
{
    public string Abi { get; }
    public string Address { get; }
    public IReadOnlyList<ContractMethod> Methods { get; } // nome, tipo (read, write, payable), parametri
    public IReadOnlyList<string> Standards { get; }       // es. ["ERC-721", "ERC-721 Metadata", "ERC-165"] o ["ARC-200"]
}
Esempio
var nft = web3.GetContract(nftAbi, "0x...");
Console.WriteLine(string.Join(", ", nft.Standards)); // ERC-721, ERC-721 Metadata, ERC-165
var reads = nft.Methods.Where(method => method.Kind == "read").Select(method => method.Name);

call, read, send, encode

call legge le funzioni read e invia una transazione per write e payable. read e send forzano l’una o l’altra cosa. Il nome della transazione nel risultato è quello del metodo. Su Algorand read è una simulazione gratuita ed encode restituisce gli argomenti dell’applicazione (selettore e valori) concatenati.

Firma
call<T = ContractResult | ITransaction>(method: string, parameters?: ContractParameters, options?: TransactionOptions): Promise<T>
read<T = ContractResult>(method: string, parameters?: ContractParameters): Promise<T>
send(method: string, parameters?: ContractParameters, options?: TransactionOptions): Promise<ITransaction>
encode(method: string, parameters?: ContractParameters): string
Esempio
await token.call('balanceOf', { account: '0x...' });          // '1000000': lettura, gratuita
await token.call('transfer', { to: '0x...', amount: '1000' });   // ITransaction, quando è nel blocco
await token.call('deposit', { note: 'grazie' }, { value: '1000000000000000' }); // payable: 0,001 ETH in wei
await token.read('approve', { spender: '0x...', amount: '1' });  // simulazione, senza transazione
await nft.call('safeTransferFrom(address,address,uint256)', { from, to, tokenId: 1 }); // scelta tra omonimi
token.encode('transfer', { to: '0x...', amount: '1000' });      // '0xa9059cbb...': dati da firmare altrove
Firma
// parameters: JsonObject, dizionario o oggetto anonimo, es. new { to, amount = "1000" }
Task<JsonNode?> CallAsync(string method, object? parameters = null, TransactionOptions? options = null,
    CancellationToken cancellationToken = default)
Task<JsonNode?> ReadAsync(string method, object? parameters = null, CancellationToken cancellationToken = default)
Task<TransactionResult> SendAsync(string method, object? parameters = null, TransactionOptions? options = null,
    CancellationToken cancellationToken = default)
string Encode(string method, object? parameters = null)
Esempio
await token.CallAsync("balanceOf", new { account = "0x..." });         // "1000000": lettura, gratuita
await token.CallAsync("transfer", new { to = "0x...", amount = "1000" }); // la transazione, in JSON
await token.SendAsync("deposit", new { note = "grazie" }, new TransactionOptions { Value = 1_000_000_000_000_000 });
await token.ReadAsync("approve", new { spender = "0x...", amount = "1" }); // simulazione, senza transazione
token.Encode("transfer", new { to = "0x...", amount = "1000" });         // "0xa9059cbb...": dati da firmare altrove

mintNft, getTokenInfo

Disponibili sui contratti ERC-20 e ARC-200 (solo getTokenInfo), ERC-721, ERC-1155 e ARC-72; sugli altri restituiscono NOT_SUPPORTED. Su Algorand mintNft usa anche arc72_mint e gli ID arrivano dagli eventi arc72_Transfer o dagli asset creati dall’applicazione. Gli URI ERC-1155 con {id} vengono completati con l’ID in 64 cifre esadecimali.

Firma
mintNft(parameters: ContractParameters, options?: TransactionOptions): Promise<INftMint>
getTokenInfo(tokenId?: string | number | bigint): Promise<ITokenInfo>
Esempio
const minted = await nft.mintNft({ to: '0x...', uri: 'ipfs://bafy...' }); // safeMint(address,string)
minted.tokenIds;   // ['1']
await nft.getTokenInfo(minted.tokenIds[0]);
// { standard: 'ERC-721', address, tokenId: '1', name: 'Art', symbol: 'ART', totalSupply: '1', owner: '0x...', tokenURI: 'ipfs://bafy...' }
await token.getTokenInfo(); // ERC-20: { standard: 'ERC-20', address, name, symbol, decimals: '18', totalSupply }
Firma
Task<NftMint> MintNftAsync(object parameters, TransactionOptions? options = null, CancellationToken cancellationToken = default)
Task<TokenInfo> GetTokenInfoAsync(string? tokenId = null, CancellationToken cancellationToken = default)
Esempio
var minted = await nft.MintNftAsync(new { to = "0x...", uri = "ipfs://bafy..." }); // safeMint(address,string)
Console.WriteLine(minted.TokenIds[0]); // "1"
var info = await nft.GetTokenInfoAsync(minted.TokenIds[0]); // Name, Symbol, Owner, TokenURI
var coin = await token.GetTokenInfoAsync();                 // ERC-20: Name, Symbol, Decimals, TotalSupply
