Integrazioni

Express

Router REST con middleware di errore.

npm install express @certifie/web3-service multer
pnpm add express @certifie/web3-service multer
yarn add express @certifie/web3-service multer
bun add express @certifie/web3-service multer

Questo esempio accetta anche il file intero (con multer) e calcola l’hash sul server. Express 5 inoltra automaticamente al middleware di errore le promise rifiutate.

server.ts
import express, { type ErrorRequestHandler } from 'express';
import multer from 'multer';
import { createHash } from 'node:crypto';
import { Web3Error, Web3Service } from '@certifie/web3-service';
import { notarizerAbi } from './notarizer-abi.js';
import { httpStatus } from './http-status.js';

const web3 = new Web3Service(process.env.RPC_URL!, {
  signer: { mnemonic: process.env.MNEMONIC!, walletIndex: 1 },
});
const contract = process.env.CONTRACT_ADDRESS!;
const upload = multer({ storage: multer.memoryStorage(), limits: { fileSize: 50 * 1024 * 1024 } });

const app = express();
app.use(express.json());

// Solo l'hash, calcolato dal client
app.post('/notarize', async (req, res) => {
  const { hash, metadata } = req.body;
  res.json(await web3.mint(notarizerAbi, contract, { hash: { data: hash, algorithm: 'sha2' }, metadata }));
});

// Il file intero: l'hash viene calcolato qui e il file non viene conservato
app.post('/notarize/file', upload.single('file'), async (req, res) => {
  if (!req.file) return void res.status(400).json({ message: 'Campo file mancante.' });
  const hash = createHash('sha256').update(req.file.buffer).digest('hex');
  res.json(await web3.mint(notarizerAbi, contract, { hash: { data: hash, algorithm: 'sha2' }, metadata: req.file.originalname }));
});

app.get('/transactions/:hash', async (req, res) => {
  res.json(await web3.getTransactionReceipt(req.params.hash));
});

const errors: ErrorRequestHandler = (error, _req, res, next) => {
  if (error instanceof Web3Error) return void res.status(httpStatus(error)).json(error.toJSON());
  next(error);
};
app.use(errors);

app.listen(3000);
Nota

Con Express 4 avvolgi gli handler asincroni in un try/catch e chiama next(error), oppure usa express-async-errors.
