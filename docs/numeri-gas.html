Numeri e gas

Interi come stringhe e costo esatto nell’unità minima.

Tutti i valori numerici restituiti sono stringhe di interi: numeri di blocco, gas, timestamp in millisecondi, indici dei log e numeri letti dai contratti. In questo modo nessun valore perde precisione oltre Number.MAX_SAFE_INTEGER e il risultato è serializzabile in JSON senza conversioni. I calcoli interni usano big.js (e BigInteger in .NET).

Il risultato ha la stessa forma in tutte le versioni, C# compreso:

nativeFee

amount = gasUsed × effectiveGasPrice, nell’unità minima del token (wei su Ethereum). Per mostrarlo in ETH dividi per 10decimals al momento della visualizzazione:

app/components/fee.tsx
import Big from 'big.js';
import type { ITransaction } from '@certifie/web3-service';

// Server Component: '0.000048295 ETH'
export function Fee({ fee }: { fee: NonNullable<ITransaction['nativeFee']> }) {
  return <span>{new Big(fee.amount).div(new Big(10).pow(Number(fee.decimals))).toFixed()} {fee.symbol}</span>;
}
app.js
// Nel browser basta BigInt, senza dipendenze.
function formatUnits(amount, decimals) {
  const value = BigInt(amount);
  const unit = 10n ** BigInt(decimals);
  const fraction = (value % unit).toString().padStart(Number(decimals), '0').replace(/0+$/, '');
  return fraction ? `${value / unit}.${fraction}` : `${value / unit}`;
}

formatUnits(result.nativeFee.amount, result.nativeFee.decimals); // '0.000048295'
src/routes/notarization.ts
import Big from 'big.js';

app.post<{ Body: NotarizationDocument }>('/notarize', async request => {
  const result = await app.web3.mint(notarizerAbi, app.contractAddress, request.body);
  const fee = result.nativeFee!;
  return { ...result, feeDisplay: new Big(fee.amount).div(new Big(10).pow(Number(fee.decimals))).toFixed() }; // '0.000048295'
});
src/fee.ts
import Big from 'big.js';
import type { ITransaction } from '@certifie/web3-service';

export function formatFee(fee: NonNullable<ITransaction['nativeFee']>): string {
  return `${new Big(fee.amount).div(new Big(10).pow(Number(fee.decimals))).toFixed()} ${fee.symbol}`; // '0.000048295 ETH'
}

// in una rotta: res.json({ ...result, feeDisplay: formatFee(result.nativeFee!) })
Program.cs
using System.Globalization;
using System.Numerics;

var fee = result.NativeFee!;
var amount = (decimal)BigInteger.Parse(fee.Amount);
var display = (amount / (decimal)BigInteger.Pow(10, int.Parse(fee.Decimals))).ToString(CultureInfo.InvariantCulture); // "0.000048295"
Nota

L’importo è la commissione di esecuzione EVM. Le commissioni aggiuntive dei rollup (pubblicazione su L1) non sono incluse.

Input numerici

Le opzioni gas, gasPrice, nonce e value accettano string, bigint o number interi sicuri. Per valori grandi usa stringhe decimali o esadecimali ('0x5208'). In .NET sono BigInteger?.
