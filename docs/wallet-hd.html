API

Metodi statici

Mnemonic, wallet HD, account Algorand e utilità.

Esempio
import { Web3Service } from '@certifie/web3-service';

const mnemonic = await Web3Service.createMnemonic();          // 12 parole
const restored = await Web3Service.getMnemonic(mnemonic.phrase, 'password-opzionale');
const wallet = await Web3Service.getWallet(restored, 1);         // IWallet
const privateKey = await Web3Service.getPrivateKey(restored, 1);
console.log(wallet.address);

Web3Service.normalizeChainId(80002);        // '0x13882'
Web3Service.shrinkAddress(wallet.address);  // '0x7099...79C8', per l’interfaccia
Esempio
var phrase = Web3Service.CreateMnemonic();                 // 12 parole
var wallet = Web3Service.GetWallet(phrase, 1, "password-opzionale"); // WalletInfo
var privateKey = Web3Service.GetPrivateKey(phrase, 1, "password-opzionale");

Web3Service.NormalizeChainId(80002);           // "0x13882"
Web3Service.ShrinkAddress(wallet.Address);     // "0x7099...79C8", per l’interfaccia
MetodoRisultato
createMnemonic()Promise<Mnemonic> di ethers, 128 bit di entropia (in .NET la frase come string), per le reti EVM
getMnemonic(phrase, password?)Valida e ricostruisce un mnemonic (in .NET la password si passa a GetWallet)
getWallet(mnemonic, index = 1)IWallet al percorso m/44'/60'/0'/0/index
getPrivateKey(mnemonic, index = 1)Chiave privata esadecimale
normalizeChainId(id)Esadecimale minuscolo, senza perdita di precisione
shrinkAddress(address)Forma abbreviata per l’interfaccia
detectStandards(abi)Standard ERC o ARC riconosciuti dall’ABI, es. ['ERC-20'] o ['ARC-200']

AlgorandWallets

Gli account Algorand non sono wallet HD: ogni account ha il suo mnemonic di 25 parole, che contiene il seed della chiave Ed25519. getWallet restituisce un IWallet con path null e index '0'; privateKey è il seed di 32 byte, accettato anche come signer.privateKey.

Esempio
import { AlgorandWallets } from '@certifie/web3-service';

const mnemonic = AlgorandWallets.createMnemonic(); // 25 parole
const account = AlgorandWallets.getWallet(mnemonic);
account.address;    // 'ALGO…', 58 caratteri
account.publicKey;  // '0x…', 32 byte
account.privateKey; // '0x…', seed di 32 byte
Esempio
using Certifie.Web3.Algorand;

var mnemonic = AlgorandWallets.CreateMnemonic();   // 25 parole
var account = AlgorandWallets.GetWallet(mnemonic); // WalletInfo: Address, PublicKey, PrivateKey (seed), Path null
