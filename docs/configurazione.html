Configurazione

URI del nodo, rete, token del gas e fallback.

Il costruttore accetta una stringa (l’URI di un nodo EVM) oppure un provider. È obbligatorio solo rpcURI: gli altri campi hanno i default della blockchain. Questa pagina descrive le reti EVM (IEvmProvider); il tipo del provider sceglie la blockchain, e Algorand e Bitcoin hanno le loro pagine.

lib/web3.ts
import 'server-only';
import { Web3Service, type IEvmProvider } from '@certifie/web3-service';

// Solo l'URI (https://, wss:// o http://127.0.0.1:8545): rete e token restano quelli di Ethereum.
export const mainnet = new Web3Service('https://mainnet.example');

const amoy: IEvmProvider = {
  rpcURI: process.env.RPC_URL!,               // es. wss://polygon-amoy.example
  rpcPublicURI: process.env.RPC_FALLBACK_URL, // fallback e RPC suggerito al wallet
  chainId: process.env.CHAIN_ID,              // '80002', '0x13882' o 80002
  chainName: 'Polygon Amoy',
  nativeCurrency: { symbol: 'POL' },          // name e decimals restano 'Ether' e 18
  blockExplorerURI: 'https://amoy.polygonscan.com',
};
export const web3 = new Web3Service(amoy, { signer: { privateKey: process.env.PRIVATE_KEY! } });

Program.cs
// Solo l'URI: rete e token restano quelli di Ethereum.
var mainnet = new Web3Service("https://mainnet.example");

// Rete completa da appsettings.json; la chiave arriva da user-secrets o da un vault.
var provider = builder.Configuration.GetSection("Web3:Provider").Get<EvmProvider>()!;
builder.Services.AddSingleton(new Web3Service(provider,
    new Web3ServiceOptions { PrivateKey = builder.Configuration["Web3:PrivateKey"] }));

Valori predefiniti

CampoDefaultNote
chainId0x1Normalizzato in esadecimale minuscolo, es. 0x539
chainNameEthereumUsato anche per aggiungere la rete al wallet
nativeCurrency.nameEther
nativeCurrency.symbolETHRiportato in nativeFee.symbol

Su Algorand i default sono mainnet-v1.0, Algorand e Algo (ALGO, 6 decimali); su Bitcoin mainnet, Bitcoin e Bitcoin (BTC, 8 decimali).

Fallback e verifica della rete

Prima di ogni operazione la libreria verifica la rete: legge eth_chainId sulle reti EVM, il genesis ID su Algorand e l’hash del blocco genesi su Bitcoin. Se rpcURI non risponde o appartiene a un’altra rete prova rpcPublicURI, che può usare un protocollo diverso. Se nessun endpoint corrisponde ottieni CHAIN_ID_MISMATCH o PROVIDER_UNAVAILABLE. Un’operazione già iniziata non viene ripetuta su un altro nodo.

Suggerimento

Le connessioni WebSocket aperte dalla libreria si chiudono al termine di ogni operazione, quindi non tengono vivo il processo Node.
